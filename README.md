# 🤠 Paola's Rodeo Birthday 🐎🌵

## 🎂 Descripción

Invitación digital para celebrar el cumpleaños de **Paola**, inspirada en la estética del viejo oeste y el mundo del rodeo.

Este proyecto combina elementos del estilo *Western*, detalles vaqueros y un ambiente festivo para crear una invitación original, divertida y personalizada.

## 🌵 Temática

La invitación está inspirada en el estilo **Cowgirl & Rodeo**, incorporando una identidad visual que evoca el espíritu del viejo oeste.

## ✨ Características

- 🎀 Diseño personalizado para el cumpleaños de Paola.
- 🤠 Estética Western / Rodeo.
- 🐎 Elementos visuales inspirados en el mundo vaquero.
- 🎉 Presentación creativa de la celebración.

## 🎨 Concepto creativo

**Saddle up, it's Paola's Birthday!** 🐎

Una invitación que mezcla la diversión de un cumpleaños con el encanto del estilo vaquero, creando una experiencia especial desde el primer momento.

Diseñado y desarrollado con mucho cariño para celebrar el cumpleaños de Paola.
